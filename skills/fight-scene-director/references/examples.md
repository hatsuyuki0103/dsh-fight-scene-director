# Examples

Read only when a concrete pattern is needed. These examples demonstrate density, formatting, and decision logic. Never reuse their characters, colors, actions, locations, node count, or outcome in an unrelated request.

## Personalized Trajectory-image Prompts

Example conditions: 15 seconds, 3D realistic anime, a silver-haired female hunter with a lightning spear, a male mercenary with a battle axe, and an industrial dock.

### Initial-position Wide View

```text
参考已提供的银白短发女猎人、男佣兵和工业码头场景，生成一张16:9的3D写实动漫风格双人打斗初始站位全景图。银白短发女猎人保持白色轻装护甲、修长体型和闪电长矛，站在画面左侧集装箱坡道的中上段，身体朝向右下方中央通道，重心略微前倾，长矛斜持，呈准备借坡道加速冲刺的状态。男佣兵保持深色战术服、强壮体型和双手战斧，站在画面右侧靠近临海护栏的低处通道，正面观察女猎人的移动方向，双手持斧进入拦截准备。完整保留码头中的集装箱坡道、中央作业通道、临海护栏、远处吊机和纵深结构，双方全身入画，清楚展示高低差、距离、朝向和可利用路线，画面留出充分运动空间，不出现轨迹线、箭头、文字、数字和图例。
```

### Character Trajectory Map

```text

```

## Direct-design Melee Example

This example shows a 15-second 2D-anime melee fight. It uses mostly close combat frames, one midpoint result wide, a clear final buildup, and the default single-color finishing frame.

```markdown
【详细打斗分镜提示词】
镜头 1：0-2秒，开场镜头，中景，正机位，镜头随剑客前冲推进。
黑衣剑客延续前倾速度冲出，剑尖沿地面划出火星，随即由下向上撩向机械体胸前；机械体抬起交叉双臂迎击。

镜头 2：2-3秒，切镜，近景，低机位仰拍。
机械体双臂交叉格挡，剑刃砍在装甲上火星四溅，两人距离压到两米。

镜头 3：3-4.5秒，切镜，近景，侧面机位。
剑客借力旋身，反手横斩机械体腰部；机械体后撤半步，剑锋擦着装甲划过，刮出一道火星。

镜头 4：4.5-5.5秒，切镜，近景，低机位。
机械体右拳砸向剑客肩部，剑客侧身卸力，绕到机械体右侧。

镜头 5：5.5-8.5秒，切镜，中远景，镜头快速拉远追拍。
剑客一脚踹中机械体胸口，机械体向后撞穿一根立柱，碎石飞散，滑出五米后单手撑地刹停。

镜头 6：8.5-9.5秒，切镜，中景，正面机位。
机械体蹬地反冲，右臂喷口喷射加速，脚下地面被踏出裂纹。

镜头 7：9.5-12.5秒，切镜，近景，侧面机位，镜头环绕半周。
机械体一拳砸向剑客，剑客压低重心从拳下穿过，反手一剑刺中机械体侧腹装甲，剑锋没入半寸，火花与金属屑迸出。

镜头 8：12.5-15秒，切镜，手部与剑锋特写转近景，明显慢镜蓄势后恢复高速。
剑客压低重心，手腕收紧，长剑沿机械体侧腹伤口回收半尺，眼神锁住装甲裂口；短暂慢镜展示剑锋重新对准裂口，随后手腕猛拧、全身力量送入横切，接触一瞬恢复高速。机械体装甲沿剑势崩开、身体踉跄后退；真实环境随即退掉，画面被高饱和暗红占满，保留双方轮廓、关键造型和长剑攻击线，装甲碎片与金属屑沿横切方向大面积铺开，短暂保持后直接结束。
```

## Character-trajectory Fight Example

Example conditions: the map fixes a swordsman's left arc, an ice mage's retreat to a right-rear platform, and two crossings. This demonstrates the required opener, ranged-versus-melee cross-cutting, route compression, supernatural light, and a decisive 2D-anime finish.

```markdown
参考人物动作轨迹图：以底图中刀客与冰系法师的初始站位确定第0秒双方的位置、距离和朝向，按照图中的人物路线、两次交汇位置、攻击方向与终点设计打斗；轨迹线、箭头、编号和文字标签只作调度参考，最终画面不显示。

【视觉风格】
视觉画风：西方奇幻2D动漫，冷调冰雪废墟、硬边阴影、清楚的动作线与冰晶轮廓。动作表现等级：夸张，刀客高速逼近，冰系法师通过远程封锁、后撤和高台维持距离。所有寒冰能力统一伴随冰蓝色能量光、发光晶体纹路与环境受光：光芒从真实触发部位汇聚，冰锥和冰墙先出现冰蓝能量轮廓再凝结，飞行与破裂保留蓝白光轨和晶体内辉，强度随招式升级。

【详细打斗分镜提示词】
镜头 1：0-1.5秒，开场镜头，中远景，摄影机沿刀客前进方向侧跟。
刀客从左侧压低重心疾冲，刀锋贴近地面沿弧线逼近；右后方的冰系法师已经向高台方向后撤，两人的距离、攻击轴线和第一处交汇位置迅速建立。

镜头 2：1.5-3秒，切镜，冰系法师手部与面部近景，摄影机轻微推近。
法师后撤中抬起右手，两指旋转收拢，冰蓝能量沿指尖和手腕纹路聚集，冷光映亮眼睛与脸侧；三道透明冰锥在掌前由发光晶体纹路快速凝结，内部保持冰蓝辉光，尖端同时锁定刀客方向。

镜头 3：3-5秒，切镜，刀客过肩近景，摄影机高速后退。
三道冰锥拖着冰蓝光轨迎面射来，刀客拨碎第一道、旋腕劈开第二道，发光冰屑从镜头两侧掠过；第三道擦过右肩，他顺势侧滑到轨迹标出的外侧位置，继续缩短距离。

镜头 4：5-6.5秒，切镜，冰系法师单人中近景，低机位轻微仰拍。
法师退到高台前骤然停步，双掌向地面压下，冰蓝能量沿石地裂缝高速向刀客方向蔓延，先勾亮墙体轮廓，再凝结成带内部蓝光的厚重冰墙；墙根雪粒和雾气被蓝光照亮。

镜头 5：6.5-8.5秒，切镜，刀客单人中景，低机位侧向追拍。
刀客踩上冰墙斜裂的边缘连续踏出两步，越过墙顶向第一处交汇点下落，双手举刀由上向下劈向法师左肩，刀锋切开墙顶时带出发光冰晶。

镜头 6：8.5-10.5秒，切镜，近景，摄影机在第一处交汇点外侧横移。
法师向右滚出下劈路线，反手将一道冰蓝发光冰符贴向刀客持刀腕；刀客收肘让冰符擦过护腕，落地后用刀背扫开寒气，两人错身分开。法师继续退向高台，刀客沿既定弧线紧追。

镜头 7：10.5-12.5秒，切镜，冰系法师手部近景转单人中景，摄影机沿攻击方向后拉。
法师踏上高台前沿，五指猛然张开，掌心冰蓝能量核心向外扩成发光圆环；高台边缘亮起密集晶纹，一道带强烈内辉的冰浪沿第二处交汇方向推出，透明冰棱、蓝白光带和被照亮的冷雾共同压向刀客。

镜头 8：12.5-15秒，切镜，刀客持刀手与刀锋特写转近景，明显慢镜蓄势后恢复高速。
刀客贴着冰浪侧缘闯入第二处交汇点，长刀劈开最薄的一层发光冰棱，再与法师临时凝成的冰蓝短刃连续碰撞两次；第二次碰撞让法师手臂外张，胸前护体冰层出现裂口。刀客压低重心，双手将长刀回收半尺，短暂慢镜展示刀尖锁定裂口；他随即从下向上挑断护体冰层，刀背撞中肩口，法师沿轨迹终点跌下高台。接触一瞬转为高饱和冰蓝单色终结帧，保留双方轮廓、刀锋、冰刃和发光碎冰，短暂保持后结束。
```

## Tracking with Cuts versus True One-take

Tracking does not prohibit cuts. A normal tracking fight can use 6–9 varied shots while preserving route, direction, speed, and landmarks. A true one-take is one continuous camera path and is used only when explicitly requested.

Normal tracking shot pattern:

```text
开场侧跟追逐 → 低机位迎拍跨越障碍 → 单人近景急停转身 → 贴身横移接住攻防 → 正面后退拍清护栏撞击 → 腿部近景蓄势并拉远交代最终结果。
```

True one-take pattern:

```text
一个0-15秒连续镜头：摄影机先侧跟追逐，借立柱遮挡绕到正面，迎面后退承接近身攻防，再横移至护栏外侧；人物的位置、方向、速度和攻击动作在摄影机绕行中连续发生，不切镜，不因重新构图而重启动作。
```
