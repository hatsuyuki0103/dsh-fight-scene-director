# 多画风打戏导演（Fight Scene Director）

作者：**AIZAO Aloong**

一个用于设计 AI 视频打戏的 Skill。它可以根据文字设定、人物与场景参考、初始站位图或轨迹图，完成动作编排、空间调度、镜头设计、特效规则和节奏梳理。

Skill 输出结构化中文提示词，适用于 **Seedance 2.0、Seedance 2.5、MiniMax H3** 等 AI 视频模型。

## 主要功能

- 直接根据角色、武器、能力、场景、画风和时长设计完整打戏。
- 提供初始站位图、人物动作轨迹图、人物与摄影机双轨迹图的生成提示词。
- 读取用户提供的角色图、场景图、站位图和轨迹图，并按素材职责组织提示词。
- 根据近战、远程、法术、群战、召唤、变身等类型调整动作与镜头。
- 支持 15 秒、30 秒及自定义时长，并在正式提示词后附带可调整的打斗节奏梳理。
- 保持人物、武器、能力、场景破坏和空间位置在镜头间连续。

## 使用方式

安装后请显式调用：

```text
$fight-scene-director
```

你可以直接附上人物、武器、场景或站位参考图，并说明画风、时长和打斗要求；也可以选择轨迹图引导模式，让 Skill 先生成三份定制的轨迹规划生图提示词。

## 安装

将本仓库文件夹复制到 Codex 的 Skills 目录：

```text
~/.codex/skills/fight-scene-director
```

重新启动或刷新 Codex 后，使用 `$fight-scene-director` 调用。

## 语言说明

内部知识与工作流使用英文编写；与用户的交流说明跟随用户语言；所有用于图片生成和视频生成的可复制提示词统一输出中文。
